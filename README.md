
# Python Password Generator

A minial password generator built on python using the random library. This tool will generate a password with 10 digits and includes special characters and numbers for maximum security.


## Installation

Install the password generator with the following steps:

* Download the source code as a .zip file from the github repository (Click the green "code" button then select "Download Zip")
* Extract the newly downloaded .zip file
* Open up your terminal and navigate to the extracted folder (cd <Extracted_Folders_Directory>)
* Run with the command "python pass_gen.py"

Upon running the terminal will output the newly generated password for you to copy and use as you wish!
